    Правила расчёта

    Чтобы показатели были однозначно интерпретируемы

    Активные в мониторинге — текущие карточки реестра со значением is_active = 1. Этот показатель не является историческим срезом на дату в прошлом.

    Созданы в источнике — карточки, для которых дата из колонки XLSX дата создания попадает в выбранный период. Для старых записей до внедрения импорта дата может отсутствовать.

    Изменённые карточки — уникальные площадки с хотя бы одним изменением API. Изменения полей — общее число строк изменений, поэтому оно может быть больше количества карточек.

    Сняты по 404 — только финальные события снятия после подтверждённого отсутствия карточки на Инвесткарте РФ; снятие по смене статуса XLSX считается отдельно.
